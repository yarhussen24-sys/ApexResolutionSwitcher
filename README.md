# ApexResolutionSwitcher

A Windows utility for switching display resolutions and refresh rates when playing Apex Legends.

ApexResolutionSwitcher helps you configure your preferred display settings for Apex Legends, with automatic game detection and restoration of your previous display settings.

## Features

- **Resolution switching:** Select your preferred display resolution.
- **Refresh rate selection:** Choose a supported refresh rate for your display.
- **Automatic Apex detection:** Detects Apex Legends running under DX11 or DX12.
- **Automatic restoration:** Restores your previous display settings when Apex Legends closes.
- **Settings persistence:** Saves your configuration between launches.
- **Display selection:** Select the display you want to configure.

3. Save it to a folder on your Windows PC.
4. Double-click the executable to launch the application.
5. If Windows displays a security warning, verify that you downloaded the file from this official repository before deciding whether to run it.

No separate installer is listed for this release.

## How to Use

1. Launch ApexResolutionSwitcher.
2. Select the display you want to configure.
3. Choose your preferred resolution and refresh rate from the available options.
4. Apply or save your settings using the application's controls.
5. Launch Apex Legends and verify that the desired display settings are applied.
6. Close Apex Legends and check that your previous display settings are restored.

Available options may depend on your monitor, Windows display configuration, and the application version.

## Troubleshooting

**The application does not launch**
- Confirm that you downloaded the executable from the official GitHub Releases page.
- Check whether Windows Security or your antivirus software has quarantined the file.
- Make sure your Windows installation meets the application's requirements.

**My desired resolution or refresh rate is unavailable**
- Check that your monitor supports the selected mode.
- Verify your Windows display settings and monitor configuration.
- Some resolutions and refresh rates may not be available on every display.

**My display settings are not restored**
- Check the application's configuration and ensure the application remains running as intended while Apex Legends is open.
- If necessary, manually restore your preferred resolution and refresh rate in Windows Display Settings.
